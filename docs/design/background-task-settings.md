# 后台任务开关

入口：设置 → DSH Tavern → 后台结算。配置保存在 profile 的 tavern-settings.json 的 backgroundTasks 中。

- posture：默认 true，允许关闭人物姿势结算。
- characterDesign：默认 false，允许开启人物设计档案。结算与候选生成均遵守此设置。
- MVU 变量结算强制执行，不提供开关，也不接受 variables 配置项。普通卡没有变量结算。

每次派发任务时读取配置，所有游戏的后续任务均生效。已运行任务使用派发时的配置完成本轮；不删除已有档案、姿势或历史。

普通卡两项均关闭时，不调用后台模型，但仍走原生结算完成流程，避免阻塞后续候选生成、回退和重新生成。只开启人物设计时不要求姿势提交。MVU 关闭姿势时直接提交变量，仍执行原有校验、重试和恢复流程。

共享后台 Session 的固定提示和完整工具目录保持不变。每轮末尾的任务协议与工具执行权限根据开关调整，不因开关修改前缀。关闭的工作不再派发；工具执行限制用于防止旧历史引发误调用。工具定义仍占上下文，不承诺特定缓存命中率或节省比例。

验证：设置持久化、普通卡全部关闭与仅设计、MVU 无姿势直接结算及关闭工具拦截、稳定工具目录回归；浏览器检查独立保存与默认值。
